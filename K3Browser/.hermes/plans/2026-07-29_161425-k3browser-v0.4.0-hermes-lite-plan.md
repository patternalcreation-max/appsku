# K3Browser v0.4.0 Hermes-Lite Implementation Plan

> **Untuk Hermes:** gunakan plan ini sebagai handoff arsitektur. Jangan implement sebelum plan disetujui.

**Goal:** Mengubah K3Browser v0.3.1 dari “Ask Page + manual tools” menjadi runtime browser-only ala Hermes: observe → reason → tool call → safety approval → execute → observe, tetap sideload-safe untuk iOS 15.

**Architecture:** Refactor monolith `Browser/BrowserView.swift` menjadi modul kecil: BrowserCore, PagePerception, AgentCore, SafetyUI, Storage, dan UI. Runtime hanya memakai API aman: SwiftUI, WebKit/WKWebView, URLSession, Keychain, UserDefaults, sandbox file storage, ShareSheet. Tidak ada App Groups, extensions, NetworkExtension, iCloud, Associated Domains, external packages, atau entitlement baru.

**Tech Stack:** Swift 5, SwiftUI iOS 15, WebKit, Security/Keychain, Foundation JSON, XcodeGen `project.yml`, GitHub Actions macos-15, unsigned build/IPA untuk Feather/KSign.

### In scope

1. **AgentLoop** dengan batas step, cancel/stop, state machine sederhana.

- Multi-tab penuh/session restore.
- Screenshot/OCR.
- Downloads/import files.
- Workflow recipes editor.
- Optional Hermes relay.
- Background monitoring.
- Autofill extension/Safari extension/default browser entitlement.

## 3. Hermes-Lite Runtime Contract

### 3.1 AgentLoop state machine

State minimal:

```text
idle
capturingSnapshot
callingModel
waitingForApproval
executingTool
completed
failed
cancelled
```

Loop:

1. User mengetik command di `CommandView`.
2. `AgentLoop.start(command:)` reset log dan set max steps default 8.
3. Observe: capture `DOMSnapshotV2`.
4. Reason: call `LLMClient` dengan prompt tool schema.
5. Parse: `ToolCallParser` baca JSON dari model.
6. Safety: `SafetyGate.evaluate(toolCall, snapshot, currentURL)`.
7. Jika `.autoAllow`: execute langsung.
8. Jika `.needsApproval`: push `ApprovalRequest` ke queue, pause.
9. Jika `.blocked`: log blocked result, lanjut/stop sesuai model instruction.
10. Execute: `ToolExecutor` menjalankan tool.
11. Observe ulang setelah tool yang mengubah page; lanjut sampai done/maxSteps/cancel.

Stop button harus membuat loop tidak mengeksekusi pending step berikutnya dan tidak menjalankan approval yang belum disetujui.

### 3.2 ToolCall JSON schema

LLM diminta output **hanya JSON** salah satu bentuk:

```json
{"type":"tool_call","tool":"snapshot_page","arguments":{},"reason":"Need current DOM"}
```

```json
{"type":"final","message":"Done. I searched for ..."}
```

Model Swift:

```text
ToolCall
  id: UUID local-generated
  tool: String
  arguments: [String: JSONValue]
  reason: String?

AgentResponse
  case toolCall(ToolCall)
  case final(message: String)
```

Parser requirements:

- Trim markdown fences jika model membungkus JSON.
- Tolak non-object JSON.
- Tolak unknown `type`.
- Tolak unknown `tool` sebelum execute.
- Batas ukuran response, misal 64 KB.
- Error parser masuk action log, tidak crash UI.

### 3.3 Tool registry v0.4.0

| Tool | Args | Risk | Behavior |
|---|---|---|---|
| `snapshot_page` | `{}` | auto | capture DOMSnapshotV2 |
| `extract_links` | `{ "limit": Int? }` | auto | return structured links |
| `save_note` | `{ "title": String, "body": String }` | auto | local memory note only |
| `scroll` | `{ "direction": "up/down", "amount": Int? }` | approve | JS scroll current page |
| `open_url` | `{ "url": String }` | approve/block by domain | load URL in same WKWebView |
| `fill_selector` | `{ "selector": String, "value": String }` | approve; block password/2FA | focus + set input/change events |
| `click_selector` | `{ "selector": String }` | approve; block dangerous text | scroll into view + click |
| `final` | `{ "message": String }` | auto | end loop |

### 3.4 SafetyGate policy

Auto-allowed:

- Snapshot/read-only extraction.
- Save local note (body generated by model, no network/share).
- Final answer.

Requires approval:

- `click_selector`, `fill_selector`, `scroll`, `open_url`.
- Clipboard/export/share only if later added and user taps explicit UI.

Blocked or extra-confirm in v0.4.0:

- Filling password fields, OTP/2FA fields, credit card fields.
- Clicking elements whose text/aria/value suggests: buy, pay, purchase, delete, remove, submit order, send money, transfer, swap, approve wallet, connect wallet, sign, confirm payment.
- Navigation to custom schemes (`itms-services`, `wallet`, unknown non-http(s) schemes).
- File upload selectors.

Approval tray displays:

- Tool name.
- Reason from model.
- Current domain.
- Selector/value preview with sensitive masking.
- Matched element label if available from DOMSnapshotV2.
- Risk reason.
- Buttons: `Run once`, `Deny`, `Edit`.

No “approve all future actions” in v0.4.0.

## 4. DOMSnapshotV2 Design

`DOMSnapshotV2` harus `Codable` dan compact untuk prompt.

Fields:

```text
DOMSnapshotV2
  capturedAt: Date
  title: String
  url: String
  visibleText: String clipped 12000
  headings: [DOMHeading]
  links: [DOMLink]
  controls: [DOMControl]
  forms: [DOMForm]
  tables: [DOMTableSummary]

DOMElementRef
  index: Int
  tag: String
  selector: String
  text: String
  ariaLabel: String?
  role: String?
  isVisible: Bool
  rect: DOMRect?

DOMControl extends/ref
  type: String?
  name: String?
  placeholder: String?
  valuePreview: String?       # mask password/hidden
  required: Bool
  disabled: Bool
```

JS extractor requirements:

- Generate stable selector: id → name → aria-label/placeholder → nth-of-type fallback.
- Use `CSS.escape` only if available; provide fallback escape function for older WebKit.
- Limit arrays: headings 80, links 150, controls 150, forms 50, tables 30.
- Mask password values; never return password value.
- Include visibility via rect and computed style.
- Return JSON string, decode in Swift with `JSONDecoder`.
- Keep old `PageSnapshot.summaryText` by deriving from DOMSnapshotV2 for UI parity.

## 8. Risks dan Mitigasi

- **LLM returns prose instead of JSON.** Mitigate with strict prompt, fenced JSON stripping, parser errors in log, retry once with “JSON only”.
- **Selector fragility.** Mitigate with DOMSnapshotV2 stable selector strategy and editable approval tray.
- **Accidental dangerous clicks.** Mitigate with deny-by-default for mutating tools, risk keywords, no approve-all.
- **iOS 15 SwiftUI API mismatch.** Avoid iOS 16+ APIs such as sheet detents unless guarded.
- **Monolith refactor regression.** Split in no-behavior-change tasks and build after each move.
- **CI/test target churn.** Keep XCTest optional; never block Release build stability on complex simulator setup.
- **Sensitive data in logs.** Mask API keys, password values, OTP/card-like fields before logging/export.
